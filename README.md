# FishPipe releases

This repository contains only the signed release APK and release metadata used by the FishPipe updater.

- `releases/latest.json`
- `releases/fishpipe-release.apk`
- `releases/release-notes.md`

## Updating FishPipe

The updater reads `releases/latest.json` and downloads `releases/fishpipe-release.apk` from this public repository. No GitHub token is required.
